# Nozomi (Crylic)

Nozomi is a custom Minecraft launcher.

## Disclaimer

NOT AN OFFICIAL MINECRAFT PRODUCT.
NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

Minecraft is a trademark of Mojang Studios. This project is not affiliated
with, endorsed by, or connected to Mojang or Microsoft in any way.

Nozomi is a custom launcher for everyone who legally owns Minecraft: Java Edition.

All user information is stored locally, and never sent to any other services or servers.

## Roadmap

Development status: On-going. Just displays a Material 3 You themed page.

### Essential features (first-release)

- [ ] Microsoft authentication (required)
  - [ ] **Checks Minecraft ownership**
  - [ ] Fetch user information (Access token, Minecraft Skin, etc.)
- [ ] Fetch version manifests
- [ ] Download and manage Minecraft resources
- [ ] Launch Minecraft

### Advanced features (second-release)

- [ ] Download and manage user-created content (mods, maps, resources, etc.)

## Development

### Development setup

- [Node.js](https://nodejs.org) v24.18 or upper (Runtime)
- [Visual Studio Code](https://code.visualstudio.com/) (Editor)
- pnpm (Package manager)

### Required Visual Studio Code extensions

- [Vue](https://marketplace.visualstudio.com/items?itemName=Vue.volar)
- [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint)
