# Nozomi (Crylic)

Nozomi는 마인크래프트 커스텀 런처입니다.  
기본적인 기능부터 시작하여 점차 많은 기능을 지원할 예정입니다.

## 면책 조항

NOT AN OFFICIAL MINECRAFT PRODUCT.
NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

Minecraft is a trademark of Mojang Studios. This project is not affiliated
with, endorsed by, or connected to Mojang or Microsoft in any way.

Nozomi는 Minecraft: Java Edition을 구매하여 보유한 사용자가 사용할 수 있는 런처입니다.

모든 사용자 정보는 사용자 기기에만 저장되며 다른 제3자 서비스 및 서버로 전송되지 않습니다.

## 로드맵

개발 현황: 개발 중. Material 3 You 페이지만 표시됨.

### 필수 기능 (최초 Release)

- [ ] Microsoft 인증 (필수)
  - [ ] **Minecraft 소유 정보 확인**
  - [ ] 사용자 정보 가져오기 (Access token, 스킨 등)
- [ ] 버전 정보 가져오기
- [ ] Minecraft 리소스 다운로드 및 관리
- [ ] Minecraft 실행

### 고급 기능 (다음 Release)

- [ ] 사용자 창작 콘텐츠 다운로드 및 관리 (모드, 맵, 리소스 팩 등)

## 개발

### 개발 환경 세팅

[Node.js](https://nodejs.org) v24.18 이상에서 구동 및 빌드가 가능하며 에디터로 [Visual Studio Code](https://code.visualstudio.com/)를 권장합니다.  
패키지 매니저는 PNPM을 사용합니다.

### Visual Studio Code 필수 확장 프로그램

- [Vue](https://marketplace.visualstudio.com/items?itemName=Vue.volar)
- [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint)
